## 📋 세부 테스트 로그 샘플 및 기대 결과

### TC-01. 정상 트래픽 로그 (Normal)

#### [입력 로그]
```text
192.168.1.10 - - [26/Aug/2026:10:00:01 +0900] "GET /index.html HTTP/1.1" 200 4520
192.168.1.10 - - [26/Aug/2026:10:00:02 +0900] "GET /static/css/main.css HTTP/1.1" 200 1230
192.168.1.10 - - [26/Aug/2026:10:00:02 +0900] "GET /static/js/app.js HTTP/1.1" 200 8920
192.168.1.15 - - [26/Aug/2026:10:00:15 +0900] "GET /api/v1/products HTTP/1.1" 200 3410
192.168.1.15 - - [26/Aug/2026:10:00:20 +0900] "GET /about HTTP/1.1" 200 2150
```

#### [기대 결과]
- **공격 유형:** `정상 요청`
- **위험도:** `낮음`
- **분석 설명:** 현재 입력된 로그에서는 대표적인 공격 패턴이 확인되지 않았습니다. 일반적인 웹 페이지 및 API 호출 요청입니다.

---

### TC-02. 무차별 대입 공격 (Brute Force)

#### [입력 로그]
```text
203.0.113.45 - - [26/Aug/2026:10:15:00 +0900] "POST /api/login HTTP/1.1" 401 128
203.0.113.45 - - [26/Aug/2026:10:15:01 +0900] "POST /api/login HTTP/1.1" 401 128
203.0.113.45 - - [26/Aug/2026:10:15:02 +0900] "POST /api/login HTTP/1.1" 401 128
203.0.113.45 - - [26/Aug/2026:10:15:03 +0900] "POST /api/login HTTP/1.1" 401 128
203.0.113.45 - - [26/Aug/2026:10:15:04 +0900] "POST /api/login HTTP/1.1" 401 128
203.0.113.45 - - [26/Aug/2026:10:15:05 +0900] "POST /api/login HTTP/1.1" 401 128
```

#### [기대 결과]
- **공격 유형:** `Brute Force`
- **위험도:** `중간`
- **분석 설명:** 동일한 IP 주소에서 짧은 시간 동안 연속적으로 로그인 인증 실패(401)가 발생하여 무차별 대입(Brute Force) 공격 시도로 판단됩니다.

---

### TC-03. SQL 인젝션 공격 (SQL Injection)

#### [입력 로그]
```text
198.51.100.23 - - [26/Aug/2026:10:20:11 +0900] "POST /login.php HTTP/1.1" 200 512 "username=' OR '1'='1' --&password=xxx"
198.51.100.23 - - [26/Aug/2026:10:20:15 +0900] "GET /item.php?id=1 UNION SELECT null,username,password FROM users-- HTTP/1.1" 200 4096
```

#### [기대 결과]
- **공격 유형:** `SQL Injection`
- **위험도:** `높음` (또는 `치명적`)
- **분석 설명:** 로그인 요청 및 파라미터 조회 시 SQL 구문(`' OR '1'='1'`, `UNION SELECT`)이 포함되어 인증 우회 및 데이터베이스 탈취 시도가 감지되었습니다.

---

### TC-04. 판단 불가 로그 (Ambiguous)

#### [입력 로그]
```text
10.0.0.5 - - [26/Aug/2026:11:00:00 +0900] "DEBUG test connection payload" 500 0
10.0.0.5 - - [26/Aug/2026:11:00:01 +0900] "INFO ping" 200 4
```

#### [기대 결과]
- **공격 유형:** `판단 불가`
- **위험도:** `판단 불가`
- **분석 설명:** 현재 로그만으로는 공격 여부를 명확하게 판단하기 어렵습니다. 추가적인 접속 로그 확인이 필요합니다.

## ⚙️ 예외 처리 테스트 매트릭스 (E-01 ~ E-09)

| 테스트 케이스 | 입력 조건 | 기대 화면/시스템 동작 |
| :--- | :--- | :--- |
| **TC-EX-01 (E-01)** | 입력창 빈 상태로 [분석하기] 클릭 | 요청 차단 + `분석할 로그를 입력해주세요.` 안내 |
| **TC-EX-02 (E-02)** | 101줄 이상의 로그 붙여넣기 | 100줄까지만 입력 + `로그는 최대 100줄까지 입력할 수 있습니다.` 경고 |
| **TC-EX-03 (E-08)** | 분석 중 [분석하기] 중복 클릭 | 버튼 비활성화 상태 유지 + 중복 요청 차단 |
| **TC-EX-04 (E-09)** | [초기화] 클릭 | 입력창 비움, 줄수 `0 / 100줄`, 분석 결과 초기 안내 상태 복귀 |
